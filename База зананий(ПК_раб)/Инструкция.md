# Инструкция: как пользоваться базой знаний через Obsidian, GitHub и ИИ-агентов

## 1. Что это за база знаний

Эта база знаний - обычная папка с Markdown-файлами, которую открывает Obsidian.

Удаленный репозиторий:

```text
git@github.com:PavelKobe/knowledge-base.git
```

Локальный путь на рабочем ПК:

```text
C:\Users\p.kobelev\База знаний\knowledge-base
```

Папка Obsidian vault:

```text
C:\Users\p.kobelev\База знаний\knowledge-base\База зананий(ПК_раб)
```

Главная заметка:

```text
C:\Users\p.kobelev\База знаний\knowledge-base\База зананий(ПК_раб)\Главная.md
```

## 2. Общая схема

```text
Obsidian = читать и связывать заметки
GitHub = синхронизация между ПК
Codex / Claude Code = помощники, которые читают и редактируют Markdown
```

Все инструменты работают с одной и той же папкой:

```text
knowledge-base
```

## 3. Как подключить базу знаний на новом ПК

На новом ПК выбери удобную папку, например:

```powershell
cd D:\Knowledge
```

Склонируй репозиторий:

```powershell
git clone git@github.com:PavelKobe/knowledge-base.git
```

Если SSH не настроен, можно через HTTPS:

```powershell
git clone https://github.com/PavelKobe/knowledge-base.git
```

После этого появится папка:

```text
D:\Knowledge\knowledge-base
```

## 4. Как открыть базу в Obsidian

1. Запусти Obsidian.
2. Нажми `Open folder as vault`.
3. Выбери папку с заметками:

```text
C:\Users\p.kobelev\База знаний\knowledge-base\База зананий(ПК_раб)
```

На домашнем ПК путь может быть другим, например:

```text
D:\Knowledge\knowledge-base\База зананий(ПК_раб)
```

Важно: открывай именно папку, где лежит `Главная.md`.

## 5. Как синхронизировать вручную через Git

Перед началом работы:

```powershell
cd "C:\Users\p.kobelev\База знаний\knowledge-base"
git pull
```

После изменений:

```powershell
git add .
git commit -m "Update knowledge base"
git push
```

На домашнем ПК то же самое, только путь будет свой:

```powershell
cd "D:\Knowledge\knowledge-base"
git pull
```

## 6. Как синхронизировать через Obsidian Git plugin

В Obsidian нажми `Ctrl + P` и используй команды:

```text
Obsidian Git: Pull
Obsidian Git: Create backup
```

Обычно `Create backup` делает:

```text
add -> commit -> pull -> push
```

Хорошая привычка:

1. Открыл Obsidian - сделай `Pull`.
2. Поработал с заметками - сделай `Create backup`.
3. Перешел на другой ПК - снова начни с `Pull`.

## 7. Как подключить Codex к базе знаний

Если Codex открыт в самой папке базы знаний, просто работай с файлами напрямую.

Если Codex открыт в папке другого проекта, укажи ему абсолютный путь:

```text
C:\Users\p.kobelev\База знаний\knowledge-base
```

Лучший промпт:

```text
Используй мою Obsidian базу знаний как внешний контекст.

Путь к базе:
C:\Users\p.kobelev\База знаний\knowledge-base

Сначала прочитай:
C:\Users\p.kobelev\База знаний\knowledge-base\База зананий(ПК_раб)\Главная.md

Затем посмотри папки:
- 10_Projects
- 20_Topics
- 30_Snippets

Сохраняй стиль существующих заметок.
Создавай связи через [[Название заметки]].
Если добавляешь заметки по текущему проекту, клади их в 10_Projects.
Если создаешь общие темы, клади их в 20_Topics.
Если создаешь команды или шпаргалки, клади их в 30_Snippets.
Если потребуется доступ к внешней папке, запроси разрешение.
```

## 8. Как подключить Claude Code к базе знаний

Открой терминал в папке базы знаний:

```powershell
cd "C:\Users\p.kobelev\База знаний\knowledge-base"
claude
```

Или на домашнем ПК:

```powershell
cd "D:\Knowledge\knowledge-base"
claude
```

Промпт для Claude Code:

```text
Это моя Obsidian база знаний.
Сначала прочитай Главная.md и структуру папок.
Сохраняй стиль существующих заметок.
Создавай связи через [[Название заметки]].
Не дублируй существующие темы, а связывай новые проекты с уже созданными узлами.
```

Если Claude Code открыт в папке проекта, а база знаний лежит отдельно:

```text
Работай с текущим проектом.
Моя Obsidian база знаний лежит здесь:
C:\Users\p.kobelev\База знаний\knowledge-base

Прочитай Главная.md и добавь заметки по этому проекту в базу знаний.
Если потребуется доступ к внешней папке, запроси разрешение.
```

## 9. Промпт для добавления нового проекта в базу знаний

```text
Проанализируй репозиторий:
<путь к проекту или git url>

Добавь его в мою Obsidian базу знаний:
C:\Users\p.kobelev\База знаний\knowledge-base

Сначала прочитай:
C:\Users\p.kobelev\База знаний\knowledge-base\База зананий(ПК_раб)\Главная.md

Создай заметки:
- 10_Projects/<project-name> - обзор.md
- 10_Projects/<project-name> - архитектура.md
- 30_Snippets/Команды <project-name>.md

Если в проекте есть API, данные или деплой, создай дополнительно:
- 10_Projects/<project-name> - данные и API.md
- 30_Snippets/Деплой <project-name>.md

Если нужны новые общие темы, создай их в 20_Topics.
Обнови Главная.md.
Свяжи проект с существующими заметками через [[...]].
Сохраняй стиль текущей базы знаний.
```

## 10. Промпт для обновления заметок по существующему проекту

```text
Обнови заметки в Obsidian базе знаний по проекту <project-name>.

База знаний:
C:\Users\p.kobelev\База знаний\knowledge-base

Проект:
<путь к локальному проекту>

Сначала прочитай текущие заметки проекта в 10_Projects.
Потом сравни с README, структурой файлов и ключевыми модулями проекта.
Обнови только то, что действительно изменилось.
Не удаляй существующие полезные связи.
Добавь новые связи через [[...]].
```

## 11. Промпт для создания шпаргалки команд

```text
Создай или обнови шпаргалку команд для проекта <project-name>.

База знаний:
C:\Users\p.kobelev\База знаний\knowledge-base

Файл для результата:
30_Snippets/Команды <project-name>.md

Включи:
- переход в папку проекта;
- установку зависимостей;
- запуск backend;
- запуск frontend;
- миграции;
- тесты;
- деплой или production-like запуск, если есть;
- ссылки на связанные заметки через [[...]].
```

## 12. Промпт для объяснения проекта через базу знаний

```text
Используй Obsidian базу знаний как контекст:
C:\Users\p.kobelev\База знаний\knowledge-base

Объясни мне проект <project-name> простым языком.
Начни с заметки проекта в 10_Projects.
Потом используй связанные темы из 20_Topics.
Объясни:
- зачем проект нужен;
- из каких частей состоит;
- как идет поток данных;
- какие технологии используются;
- какие файлы читать первыми;
- какие команды запускать.
```

## 13. Как избежать конфликтов между рабочим и домашним ПК

Главное правило:

```text
Перед работой - git pull
После работы - git push
```

Не редактируй одну и ту же заметку одновременно на двух ПК.

Если работаешь через Obsidian Git:

```text
Открыл Obsidian -> Pull
Закончил работу -> Create backup
```

## 14. Что делать, если агент не видит базу знаний

Если агент пишет, что не может прочитать путь:

1. Проверь, что путь существует.
2. Проверь, что база склонирована на этом ПК.
3. Открой агента прямо в папке `knowledge-base`.
4. Или дай агенту разрешение на чтение внешней папки.

Путь для проверки на рабочем ПК:

```text
C:\Users\p.kobelev\База знаний\knowledge-base\База зананий(ПК_раб)\Главная.md
```

## 15. Короткая формула

```text
Obsidian показывает базу знаний.
GitHub синхронизирует между ПК.
Codex и Claude Code помогают читать, объяснять и дописывать Markdown.
```

## 16. Как подключить базу знаний на домашнем ПК с нуля

Этот сценарий нужен, если ты пришел на новый ПК, например домашний, и хочешь подключить ту же Obsidian базу знаний.

### Шаг 1. Установить Git

Проверь, установлен ли Git:

```powershell
git --version
```

Если Git не установлен, скачай его с официального сайта:

```text
https://git-scm.com/downloads
```

После установки снова проверь:

```powershell
git --version
```

### Шаг 2. Скачать Obsidian

Скачай Obsidian с официального сайта:

```text
https://obsidian.md/download
```

Для Windows выбери обычный установщик, установи и запусти Obsidian.

### Шаг 3. Склонировать базу знаний с GitHub

Выбери удобную папку на домашнем ПК, например:

```text
D:\Knowledge
```

В PowerShell:

```powershell
mkdir D:\Knowledge
cd D:\Knowledge
git clone https://github.com/PavelKobe/knowledge-base.git
```

Если настроен SSH-доступ к GitHub, можно так:

```powershell
git clone git@github.com:PavelKobe/knowledge-base.git
```

После клонирования появится папка:

```text
D:\Knowledge\knowledge-base
```

### Шаг 4. Открыть папку как Vault в Obsidian

В Obsidian:

1. Нажми `Open folder as vault`.
2. Выбери папку с заметками:

```text
D:\Knowledge\knowledge-base\База зананий(ПК_раб)
```

Важно: выбирать нужно именно папку, где лежит файл:

```text
Главная.md
```

Не выбирай только `D:\Knowledge` и не выбирай только `knowledge-base`, если хочешь открыть именно готовый vault с заметками.

### Шаг 5. Проверить, что база открылась

В Obsidian открой заметку:

```text
Главная
```

Там должны быть ссылки на проекты:

- [[shop-backend-course - учебный backend-стек]]
- [[retail-audit-kit - корпоративный аудит розницы]]
- [[VoiceScreen - голосовой AI-скрининг]]
- [[Инструкция]]

Открой `Graph view`, чтобы увидеть связи между заметками.

### Шаг 6. Как работать на домашнем ПК

Перед началом работы подтяни свежие изменения:

```powershell
cd "D:\Knowledge\knowledge-base"
git pull
```

После изменений отправь их в GitHub:

```powershell
git add .
git commit -m "Update knowledge base from home"
git push
```

### Шаг 7. Как вернуться на рабочий ПК

На рабочем ПК перед началом работы выполни:

```powershell
cd "C:\Users\p.kobelev\База знаний\knowledge-base"
git pull
```

После работы:

```powershell
git add .
git commit -m "Update knowledge base from work"
git push
```

Главное правило:

```text
Один ПК закончил работу -> git push
Другой ПК начал работу -> git pull
```

Так Obsidian база знаний будет одинаковой на рабочем и домашнем ПК.
