Один сбой связывает пять концепций

Это не отдельные опции — это одна причинно-следственная цепочка.

1. Запрос зависКлиент не может ждать бесконечно.
2. TimeoutДедлайн прерывает ожидание, но не доказывает, что операция не выполнилась.
3. RetryКлиент повторяет запрос с backoff и jitter.
4. IdempotencyПовтор не создаёт второй заказ или платёж.
5. Rate limitМассовые повторы не превращаются в лавину.
