# Корпоративное хранилище фото

Проект [[retail-audit-kit - корпоративный аудит розницы]] умеет отдавать фото из корпоративных путей через backend-прокси.

## Где смотреть

- `backend/photo_paths.py`
- `verify_photos_prod.ps1`
- `frontend/src/utils/photo_url.js`
- `frontend/src/utils/store_photo_path.js`
- `frontend/src/components/PhotoViewerModal.jsx`
- `frontend/src/components/MediaViewerModal.jsx`
- `frontend/src/components/PhotoPathFallbackModal.jsx`

## Backend endpoint

```text
GET /api/photos?path=...
```

## Переменные окружения

- `PHOTO_ALLOWED_ROOTS`
- `PHOTO_DRIVE_MAPPINGS`

## Зачем это важно

Backend должен отдавать только разрешенные пути и не позволять path traversal. Для корпоративной сети это важная граница безопасности.
