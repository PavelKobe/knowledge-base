# Yandex SpeechKit

Yandex SpeechKit используется для STT/TTS: распознавания речи кандидата и генерации голоса агента.

## Где используется

- [[VoiceScreen - голосовой AI-скрининг]]

## Файлы проекта

- `app/core/stt.py`

## Роль

- принимать аудио из звонка;
- получать текст кандидата;
- отдавать голос агента через TTS;
- работать в потоке реального звонка.
