# Telegram Bot

Telegram bot - один из интерфейсов клиента/HR в VoiceScreen.

## Где используется

- [[VoiceScreen - голосовой AI-скрининг]]

## Файлы проекта

- `app/bot/__main__.py`
- `app/bot/handlers.py`

## Зависимость

```text
aiogram 3
```

## Роль

- связь с HR;
- быстрые команды;
- уведомления или статусы;
- привязка клиента через `tg_chat_id`.
