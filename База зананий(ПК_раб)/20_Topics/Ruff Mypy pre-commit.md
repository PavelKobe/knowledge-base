# Ruff Mypy pre-commit

Набор инструментов для качества кода.

## Роли

- Ruff: линтер и форматирование.
- Mypy: статическая проверка типов.
- pre-commit: запуск проверок перед коммитом.

## В курсе

Модуль M14 добавляет автопроверки, чтобы backend-проект был ближе к production-подходу.
