# React

React используется во frontend проекта [[retail-audit-kit - корпоративный аудит розницы]].

## Где смотреть

- `frontend/src/App.jsx`
- `frontend/src/components/`
- `frontend/src/utils/`
- `frontend/src/api.js`

## Роль в проекте

React держит состояние пользователя, активной вкладки, выбранного шаблона, истории проверок, статистики и режима редактирования.

## Главные компоненты

- `DynamicCheckForm`
- `TemplatePicker`
- `ChecklistConstructor`
- `ChecklistTemplateEditor`
- `SbRetailCheckHistory`
- `SbRetailStats`
- `SbRetailViolationsReport`
- `UserActionsLog`
- `KpiSection`
