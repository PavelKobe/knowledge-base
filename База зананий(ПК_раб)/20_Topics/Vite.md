# Vite

Vite используется для сборки и dev-сервера frontend.

## Где смотреть

- `frontend/package.json`
- `frontend/vite.config.js`
- `frontend/vercel.json`

## Команды

```powershell
npm run dev
npm run build
npm run preview
```
