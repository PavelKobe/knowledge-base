# Redis

Redis обычно используется как кеш, broker/result backend или быстрый key-value storage.

## В курсе

Модуль M11 посвящен Redis-кешированию каталога.

## Что важно понять

- кеш ускоряет чтение часто запрашиваемых данных;
- кеш нужно инвалидировать при изменениях;
- Redis часто используется вместе с [[Celery]], но в этом курсе для Celery отдельно указан [[RabbitMQ]].
