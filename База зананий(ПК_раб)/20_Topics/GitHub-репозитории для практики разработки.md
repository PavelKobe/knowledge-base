# GitHub-репозитории для практики разработки

Подборка из видео [«Топ GitHub-репозиториев, которые должен знать каждый разработчик»](https://youtube.com/shorts/xi3g4iZxiWE). Репозитории помогают перейти от чтения теории к практике: выбрать идею, пройти проектный туториал или самостоятельно воссоздать известную технологию.

## Краткий рейтинг

| Место в видео | Репозиторий | Для чего подходит |
|---:|---|---|
| 1 | [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) | Глубокое понимание технологий через создание собственных реализаций |
| 2 | [practical-tutorials/project-based-learning](https://github.com/practical-tutorials/project-based-learning) | Обучение языкам программирования на полноценных проектах |
| 3 | [florinpop17/app-ideas](https://github.com/florinpop17/app-ideas) | Поиск идей для практики и портфолио с готовыми требованиями |

## 1. Build Your Own X

**Ссылка:** [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x)

Коллекция пошаговых руководств по созданию известных технологий с нуля. В каталоге есть собственные базы данных, Git, Docker, веб-серверы, браузеры, операционные системы, языки программирования, нейросети, эмуляторы и другие сложные системы.

### Чем полезен

- помогает понять внутреннее устройство инструментов, а не только их публичный API;
- развивает системное мышление, отладку и навыки проектирования;
- позволяет выбрать реализацию на знакомом языке программирования;
- подходит для углублённого обучения после освоения базовых проектов.

### Как использовать

1. Выбрать технологию, которую уже доводилось применять.
2. Найти руководство на знакомом языке.
3. Сначала собрать минимальную рабочую версию, затем добавить тесты и документацию.
4. Сравнить свою реализацию с настоящим инструментом и записать обнаруженные ограничения.

## 2. Project Based Learning

**Ссылка:** [practical-tutorials/project-based-learning](https://github.com/practical-tutorials/project-based-learning)

Курируемая подборка бесплатных проектных руководств, сгруппированных по языкам программирования. Здесь есть материалы по C/C++, C#, Go, Java, JavaScript, Kotlin, Python, Rust, Swift и другим языкам. Каждый материал ведёт к созданию законченного работающего проекта.

### Чем полезен

- позволяет учить язык через создание приложений, а не через изолированные упражнения;
- охватывает web-разработку, мобильные приложения, машинное обучение, игры, ботов и системное программирование;
- помогает быстро найти практический проект под выбранный стек;
- подходит как маршрут от учебного примера к собственному проекту.

### Как использовать

1. Открыть раздел нужного языка или технологии.
2. Выбрать проект немного сложнее текущего уровня.
3. Повторить реализацию по руководству.
4. Сделать второй проход без пошаговых подсказок и добавить собственную функцию.

## 3. App Ideas

**Ссылка:** [florinpop17/app-ideas](https://github.com/florinpop17/app-ideas)

Коллекция идей приложений для тренировки и портфолио. Задания разделены на три уровня: начинающий, средний и продвинутый. Для большинства идей указаны цель, обязательные пользовательские сценарии, дополнительные функции и полезные материалы.

### Чем полезен

- снимает проблему «не знаю, что написать для практики»;
- даёт требования, но не навязывает конкретный стек или готовое решение;
- позволяет постепенно повышать сложность проектов;
- подходит для портфолио, челленджей и проверки новой технологии.

### Как использовать

1. Выбрать уровень сложности и идею.
2. Превратить пользовательские сценарии в задачи или чек-лист.
3. Самостоятельно выбрать архитектуру и технологии.
4. После обязательной части реализовать несколько дополнительных функций и опубликовать результат.

## Как выбрать репозиторий

- Нужна готовая идея и свобода реализации — **App Ideas**.
- Нужен пошаговый проект на конкретном языке — **Project Based Learning**.
- Нужно разобраться, как технология устроена изнутри — **Build Your Own X**.

## Практический маршрут

1. Начать с проекта первого или второго уровня из **App Ideas**.
2. Закрыть пробелы с помощью подходящего руководства из **Project Based Learning**.
3. Затем выбрать один системный проект из **Build Your Own X**.
4. Для каждого результата сохранить README, архитектурную схему, тесты и выводы — так упражнения превращаются в портфолио и повторно используемые знания.
