## Правило зачёта

Модуль закрывается только при наличии четырёх доказательств:

1. объяснение механизма своими словами;
2. самостоятельная реализация;
3. автоматические тесты;
4. пройденный failure lab.

AI-review не заменяет ни одно из доказательств.

## Статусы

- `not_started` — ещё не изучали;
- `theory` — идёт изучение теории;
- `practice` — выполняется самостоятельная реализация;
- `review` — первая версия готова и проверяется;
- `rework` — исправляются замечания;
- `mastered` — модуль защищён;
- `repeat` — требуется интервальное повторение.
