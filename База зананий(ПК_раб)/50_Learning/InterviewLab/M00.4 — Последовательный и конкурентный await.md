# M00.4 — Последовательный и конкурентный await

## Связь с предыдущим уроком

В [[M00.3 — Микроурок 1 Coroutine Task Event Loop]] установлено:

- вызов async-функции создаёт coroutine object;
- Task регистрирует coroutine в event loop;
- незавершённый `await` позволяет текущей Task отдать управление.

Теперь главный вопрос:

> Если в коде есть несколько `await`, обязательно ли операции выполняются конкурентно?

Нет. `await` создаёт возможность переключения, но порядок запуска операций определяет структура кода.

## 1. Последовательное выполнение

```python
first = await load_first()
second = await load_second()
```

Порядок:

```text
запустить load_first
↓
дождаться полного результата load_first
↓
только затем запустить load_second
↓
дождаться load_second
```

Если каждая операция ожидает сеть две секунды, общее время будет около четырёх секунд.

Event loop во время ожидания `load_first` может обслуживать Task других запросов приложения. Но внутри текущей Task функция `load_second` ещё даже не вызвана.

Это важное различие:

- приложение в целом может оставаться конкурентным;
- две конкретные операции внутри одного endpoint выполняются последовательно.

## 2. Конкурентное выполнение

Чтобы обе независимые операции ожидали одновременно, их нужно обе поставить в расписание:

```python
async with asyncio.TaskGroup() as group:
    first_task = group.create_task(load_first())
    second_task = group.create_task(load_second())

first = first_task.result()
second = second_task.result()
```

Упрощённая временная линия:

```text
0 сек: load_first отправила запрос и отдала управление
0 сек: load_second отправила запрос и отдала управление
2 сек: оба ответа готовы
```

Общее время — около двух секунд, а не четырёх.

Это конкурентность: ожидания перекрываются по времени. Python-код двух Task не обязательно исполняется параллельно.

## 3. Почему `await` не означает «запусти параллельно»

Строка:

```python
first = await load_first()
```

означает для текущей Task:

> Не переходи к следующей строке, пока `load_first` не даст результат.

Она не означает:

> Запусти `load_first` в фоне и сразу иди дальше.

Для отдельного конкурентного выполнения нужна Task, `TaskGroup`, `gather` или другой механизм планирования.

## 4. Когда операции нельзя запускать конкурентно

Если вторая операция зависит от первой:

```python
user = await load_user(user_id)
orders = await load_orders(user.id)
```

`load_orders` нужен `user.id`, поэтому корректный порядок последовательный.

Попытка сделать их конкурентными означает, что второй операции ещё не хватает входных данных.

Правило:

- независимые I/O-операции можно рассмотреть для конкурентного запуска;
- зависимые операции выполняются последовательно;
- конкурентность добавляют только при измеримой пользе и понятной обработке ошибок.

## 5. `TaskGroup` и `gather`

Короткая запись через `gather`:

```python
first, second = await asyncio.gather(
    load_first(),
    load_second(),
)
```

`gather` запускает awaitable конкурентно и возвращает результаты в порядке аргументов.

Для связанных дочерних задач в современном Python часто предпочтителен `TaskGroup`:

- границы жизни Task видны в `async with`;
- выход ожидает завершение задач;
- при ошибке одной задачи остальные отменяются;
- ошибки собираются структурированно.

На этом этапе достаточно понимать идею. Подробную обработку ошибок и cancellation разберём отдельно.

## 6. Практическое наблюдение

Создайте временный файл `await_timing.py`:

```python
import asyncio
from time import perf_counter


async def operation(name: str, delay: float) -> str:
    print(f"{name}: старт")
    await asyncio.sleep(delay)
    print(f"{name}: финиш")
    return name


async def sequential() -> None:
    started = perf_counter()
    first = await operation("A", 1)
    second = await operation("B", 1)
    elapsed = perf_counter() - started
    print(f"Последовательно: {first}, {second}; {elapsed:.2f} сек")


async def concurrent() -> None:
    started = perf_counter()

    async with asyncio.TaskGroup() as group:
        first_task = group.create_task(operation("A", 1))
        second_task = group.create_task(operation("B", 1))

    elapsed = perf_counter() - started
    print(
        f"Конкурентно: {first_task.result()}, "
        f"{second_task.result()}; {elapsed:.2f} сек"
    )


async def main() -> None:
    await sequential()
    print("---")
    await concurrent()


asyncio.run(main())
```
