# M00.2 — Проверка теории

Тест проверяет понимание механизма asyncio и lifecycle FastAPI. Отвечайте своими словами, не копируя формулировки из теории. Небольшой псевдокод допустим.

## 1. Путь coroutine

Что последовательно происходит от вызова функции `load_user()` до получения результата?

```python
async def load_user() -> dict[str, str]:
    ...

user = await load_user()
```

### Ответ: при вызови асинхронной функции создается объект корутина и дает возможность приостановить выполнение операции пока event loop выполняет другие операции.


## 2. Последовательность и конкурентность

Два независимых HTTP-запроса выполняются по две секунды каждый.

Сколько примерно займут эти варианты и почему?

```python
first = await load_first()
second = await load_second()
```

```python
first, second = await asyncio.gather(
    load_first(),
    load_second(),
)
```

### Ответ: второй запрос выполнится быстрее .


## 3. Момент начала выполнения

Когда фактически начнёт выполняться `work()` и почему?

```python
async def main() -> None:
    coroutine = work()
    await asyncio.sleep(1)
    result = await coroutine
```

Как изменится поведение после замены первой строки тела на:

```python
task = asyncio.create_task(work())
```

### Ответ: work() начнет выполнятся через 1 сек , после добавления asyncio.create_task ->создается задача если нет никаких ожиданий ввода/вывода она сразу выполнится.
