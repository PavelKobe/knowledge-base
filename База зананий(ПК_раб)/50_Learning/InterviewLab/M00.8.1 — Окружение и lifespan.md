# M00.8.1 — Окружение и lifespan

## Результат задачи

FastAPI-приложение создаёт один `httpx.AsyncClient` при startup и закрывает тот же объект при shutdown.

Текущий review: функциональная часть принята 2026-08-19; остаются две ошибки Ruff `I001` в импортах рабочей копии.

## Что здесь тренируется

- воспроизводимое виртуальное окружение;
- runtime и dev зависимости;
- `@asynccontextmanager`;
- код до и после `yield`;
- application-scoped ресурс;
- явное владение и cleanup.

## Шаг 1. Понять зависимость

`httpx` будет импортироваться production-кодом, поэтому это runtime dependency, а не только инструмент тестирования.

В `pyproject.toml`:

- перенесите `httpx` в основной список `dependencies`;
- не оставляйте вторую копию в `dev`;
- переустановите editable-пакет.

## Шаг 2. Реализовать lifespan

Каркас:

```text
src/interviewlab/lifecycle.py
```

Заполните `TODO`:

1. создать `httpx.AsyncClient(timeout=5.0)`;
2. сохранить его в `app.state.http_client`;
3. выполнить `yield` внутри `try`;
4. в `finally` закрыть client через async API.

Не создавайте второй client в cleanup.

## Шаг 3. Подключить lifespan

В `src/interviewlab/main.py`:

- импортируйте функцию `lifespan`;
- передайте её в конструктор `FastAPI`;
- сохраните фабрику `create_app()`;
- не меняйте `/health`.

## Методология отладки

Если приложение не стартует:

1. найдите первую строку traceback, относящуюся к вашему файлу;
2. определите этап: import, startup, request или shutdown;
3. проверьте, создан ли объект до `yield`;
4. проверьте, вызывается ли async-метод закрытия через `await`;
5. не добавляйте `try/except Exception: pass`.
