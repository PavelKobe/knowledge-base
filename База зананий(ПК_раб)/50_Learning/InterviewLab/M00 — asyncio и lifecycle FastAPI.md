# M00 — asyncio и lifecycle FastAPI

## Результат модуля

Уметь объяснить и применить coroutine, task, event loop, конкурентное I/O, timeout, cancellation и lifespan FastAPI.

## Порядок прохождения

1. Изучить фундамент [[M00.0 — Как Python исполняет Flask приложение]].
2. Пройти микроуроки, начиная с [[M00.3 — Микроурок 1 Coroutine Task Event Loop]].
3. Использовать [[M00.1 — Теория asyncio и lifecycle FastAPI]] как подробный справочник.
4. Составить краткий конспект после микроуроков.
5. Пройти короткую прикладную проверку.
6. Выполнить небольшую изолированную практику.
7. Реализовать применение темы в InterviewLab.
8. Пройти review и failure lab.
