# M00.8.2 — Dependency и health ресурса

## Начинать после

[[M00.8.1 — Окружение и lifespan]] прошла проверки.

## Результат задачи

Endpoint получает application-scoped HTTP client через FastAPI dependency, но не создаёт и не закрывает его.

## Что здесь тренируется

- dependency injection;
- разделение владения и использования;
- `Request.app.state`;
- типизация зависимости;
- подключение `APIRouter`.

## Шаг 1. Реализовать dependency

Файл:

```text
src/interviewlab/dependencies.py
```

В `get_http_client()`:

1. получите client из `request.app.state`;
2. верните существующий объект;
3. не используйте `async with`;
4. не вызывайте `aclose()`;
5. не создавайте новый `AsyncClient`.

Причина: dependency не владеет этим ресурсом. Владелец — lifespan.

## Шаг 2. Реализовать endpoint

Файл-каркас:

```text
src/interviewlab/api/system.py
```

Реализуйте `GET /health/resources`:

- client приходит через `Depends(get_http_client)`;
- проверьте свойство состояния закрытия клиента;
- верните `ready` или `closed`;
- не обращайтесь во внешний интернет.

## Шаг 3. Зарегистрировать router

Только после реализации:

- импортируйте router в `main.py`;
- подключите через `app.include_router(...)`;
- убедитесь, что `/health` продолжает работать.

## Ручная проверка

```powershell
python -m uvicorn interviewlab.main:app --reload
```

В другом терминале:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
Invoke-RestMethod http://127.0.0.1:8000/health/resources
```
