# Полезные плагины

> [!abstract] Каталог полезных плагинов, MCP-серверов и утилит
> Здесь собираются инструменты, которые стоит подключать к AI-assisted разработке, Claude Code, Codex и локальным агентам.

## 1. Microsoft MarkItDown / MarkItDown-MCP

**Назначение:** преобразование документов и других файлов в Markdown для последующей обработки LLM, RAG, индексирования и анализа.

### Официальные ссылки

- [Microsoft MarkItDown — GitHub](https://github.com/microsoft/markitdown)
- [MarkItDown MCP — GitHub MCP Registry](https://github.com/mcp/microsoft/markitdown)
- [MarkItDown-MCP — исходники MCP-сервера](https://github.com/microsoft/markitdown/tree/main/packages/markitdown-mcp)
- [Исходный ролик Instagram](https://www.instagram.com/reel/Daah0LNgdTd/?stkn=MWtwa2dsZzZmZ3JjYw==)

### Что умеет

- PDF → Markdown
- DOCX → Markdown
- PPTX → Markdown
- XLS/XLSX → Markdown
- изображения и часть мультимедийных форматов → Markdown/текст
- сохранение полезной структуры документа: заголовков, списков, таблиц и ссылок
- работа как Python-библиотека и CLI
- работа через MCP-сервер с AI-агентами

### Установка обычной версии

```bash
pip install 'markitdown[all]'
```

Только основные офисные форматы:

```bash
pip install 'markitdown[pdf,docx,pptx,xlsx]'
```

### PDF → Markdown из CLI

```bash
markitdown document.pdf -o document.md
```

или:

```bash
markitdown document.pdf > document.md
```

### Установка MCP-сервера

```bash
pip install markitdown-mcp
```

Запуск STDIO MCP-сервера:

```bash
markitdown-mcp
```

MCP предоставляет инструмент `convert_to_markdown(uri)`, который можно вызывать из совместимого AI-клиента или агента.

### Где пригодится в наших сценариях

1. Передавать PDF-документацию в Claude Code / Codex в чистом Markdown вместо тяжёлого PDF.
2. Подготавливать документы к RAG и индексации.
3. Автоматически приводить корпоративные PDF/DOCX/PPTX к формату, удобному для LLM.
4. Подключить как MCP к агентному workspace и дать агенту отдельный инструмент конвертации файлов.
5. Использовать в локальном pipeline: `документ → MarkItDown → Markdown → LLM/агент`.

> [!warning] Безопасность
> MarkItDown работает с правами процесса, из которого он запущен. Для локального MCP лучше ограничивать доступ только нужными каталогами и не открывать MCP-сервер наружу без необходимости.
